# Furniture Store

A full-stack furniture e-commerce app for browsing, buying, and booking furniture repairs. Built with Next.js, TypeScript, and TailwindCSS.

## Features
- Browse and search furniture listings
- Purchase furniture online
- Book furniture repair services

## Tech Stack
- Next.js
- TypeScript
- TailwindCSS

## Getting Started

Clone the repo and install dependencies:

\```
git clone https://github.com/tapiwa19/Furniture-store
cd Furniture-store
npm install
npm run dev
\```

Open http://localhost:3000 in your browser.
